# 🎧 Noise Vortex Pro & Masterpiece Experience

A luxury, interactive e-commerce and 3D teardown web experience inspired by Noise's flagship audio and smartwatch lineup.

---

## 🌟 Highlights & Features

### 1. 🏠 Main Flagship Store (`index.html`)
* **Hero Carousel & Ambient Backdrops**: Smoothly transitions through flagship smartwatches, Dolby Atmos soundbars, and noise-cancelling earbuds.
* **Top Picks & Dynamic Shopping Bag**: Real-time interactive cart with dynamic product updates, multi-item quantities, voucher discount (`NOISEVIP500`), and celebratory confetti checkout.
* **Interactive Web Audio Synthesizer**: Immersive UI clicks and audio feedback powered by Web Audio API (`audio.js`).

### 2. ⌚ Masterpiece 01: Watch Teardown (`masterpiece.html`)
* **240-Frame 3D Scrubber**: Smooth scroll-scrubbed mechanical exploded view of the Core One smartwatch.
* **Smoky Dark Aesthetic**: Deep atmospheric background with GSAP ScrollTrigger pacing.

### 3. 🎧 Masterpiece 02: Audira Harmony Acoustics (`masterpiece-2.html`)
* **196-Frame Planar-Magnetic Scrub**: Organic luxury aesthetic (`#e4dece` cream, warm leather brown, orange accent).
* **Pinned GSAP Timeline**: Smooth 4800px scrub with Lenis smooth scroll and interactive pre-order checkout.

---

## 🚀 Quick Start

### Option 1: Using Node.js
```bash
# Start the local server
node server.js
```
Open your browser and navigate to:
* **Store Homepage**: [http://localhost:3000](http://localhost:3000)
* **Masterpiece 01**: [http://localhost:3000/masterpiece.html](http://localhost:3000/masterpiece.html)
* **Masterpiece 02**: [http://localhost:3000/masterpiece-2.html](http://localhost:3000/masterpiece-2.html)

### Option 2: Windows Batch
Double-click `START_SERVER.bat` or `OPEN_WEBSITE.bat`.
